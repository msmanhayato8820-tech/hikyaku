# 飛脚 — 日本橋の町を駆ける（3D版）

小さな江戸風の町を自由に歩く、三人称3D配達ゲームです。
日本橋の問屋で手紙を受け取り、橋を渡って南東の配達所へ届けます。
町・道・距離・建物・人物は創作で、史実の地形や街並みの再現ではありません。

- 公開先：[飛脚を遊ぶ](https://msmanhayato8820-tech.github.io/hikyaku/)
- ソース：[GitHub](https://github.com/msmanhayato8820-tech/hikyaku)

このフォルダは同じ公開URLを3D版へ置き換えるための配布物です。
公開反映はリポジトリ管理者が行います。ローカルファイルの完成は公開完了を意味しません。

## 遊び方

1. 「町へ出る」を押す。受取前は時間制限なく探索できます。
2. 目の前の金色の柱へ近づき、「手紙を受け取る」を押す。
3. 地図の金色の線と街道上の印を目印に配達所へ進む。川は二つの橋で渡れます。
4. 配達所の柱へ近づいて「手紙を届ける」を押す。5分以内で20両獲得。

普通に歩いて配達経路を進むと約3〜4分。探索や休憩も含め5分以内を目指します。
駆け足や経路の選択で所要時間は変わります。受取前の探索時間は配達時間に含みません。
マップ上の三角が自分とカメラの向き、赤い菱形が目的地、緑の点が茶屋です。
金色の道は推奨経路で、他の通行可能な道も自由に歩けます。

### PC

| 操作 | キー・方法 |
| --- | --- |
| 移動 | WASD / 矢印（カメラ方向を基準） |
| ジャンプ | Space |
| 駆け足 | Shiftを押しながら移動 |
| 見回す | ゲーム画面をドラッグ / Q・E |
| カメラ距離 | マウスホイール |
| 道案内方向へ向き直る | 「視点を戻す」 |
| 受取・配達 | 赤いボタン / F |
| 一時停止・再開 | ボタン / Esc |

カメラは飛脚の位置を自動で追いかけます。向きはドラッグで調整します。
カメラが建物にぶつかる場合は手前に引き寄せます。

### スマホ縦画面

- 左の仮想スティックで移動。
- 右の「跳ぶ」でジャンプ。「駆け足」を押しながらスティックで走る。
- 操作ボタンのないゲーム画面をドラッグすると見回せます。
- 「視点を戻す」で道案内の方向へ向き直ります。
- 目的地で赤い受取・配達ボタンを押します。

### 休憩・保存・音

- 歩行中と停止中にスタミナが回復。駆け足とジャンプで消費します。
- 「ひと休み」は2秒の休憩。茶屋の近くでは3秒で全回復します。配達の時計は進みます。
- 一時停止中は時計も停止。別タブへ移ると自動停止します。
- 所持金・配達回数と途中の配達をlocalStorageへ保存。途中状態は約5秒ごとと一時停止時に保存します。
- 再読み込み後の「配達の続きから」で保存地点へ戻れます。「町へ出る」は新しい配達を始めます。
- 2D最小版の保存が同じオリジンにある場合、初回だけ所持金・配達回数を読み込みます。元の保存は書き換えません。
- 保存禁止のブラウザでも遊べますが、再読み込み後の記録は残りません。
- 音は初期状態OFF。「音：切」を押すと自作BGMと効果音を有効化できます。

## 実装範囲

実際のWebGL立体描画・深度バッファによる遮蔽、立体の建物・人物・橋、川と町の交差点を備えます。
建物と川・マップ境界の衝突、橋の高さ、ジャンプ、視点の回転と壁回避、地図と衝突を避ける経路案内を実装しています。

この版は手紙1種類・配達1区間・朝の町です。従来案の複数荷物、品質減価、装備購入、遠方の宿場解放、天候・昼夜、実績は含みません。
広大な連続世界ではなく、探索可能な小規模オープンマップです。人物は自作の低ポリゴンモデルです。
Canvas/WebGLを使う視覚ゲームであり、スクリーンリーダーのみでのプレイには対応していません。

## 配置・開発

HTML/CSS/JavaScriptのみ。ビルド・npm・CDNは不要です。
以下6ファイルをGitHub Pagesの公開ルートへそのまま配置します。

- `index.html`：画面構成
- `style.css`：PC・スマホのレイアウト
- `game.js`：独自WebGL描画、町の形状、ゲームと操作、保存
- `README.md`：この説明
- `LICENSE`：MIT License
- `TESTING.md`：実施した検証と未検証項目

ローカルでは同フォルダの`index.html`を開くか静的サーバーで確認できます。
HTTP配信での保存とWebGL動作を推奨します。localStorageの扱いはブラウザ・配信元によって異なります。

`game.js`の`pickup` / `delivery` / `teas`が目的地・茶屋、`house`が建物と衝突、`LIMIT`が制限時間です。
`update`がゲーム進行、`draw`が3D描画、`camera`が視点、`routePoints`が道案内を担当します。
静的な町のメッシュはまとめて描画し、requestAnimationFrameと最大1.6倍の描画解像度を使用します。
60fpsを目標としていますが、端末ごとのフレームレートは保証しません。
