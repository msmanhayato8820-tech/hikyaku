# 飛脚 — 最小版

日本橋から品川へ一通の手紙を配達する、ビルド不要のブラウザゲーム。
街道や距離・移動速度はゲーム用の創作です。歴史再現ではありません。

## 遊び方

`index.html` をブラウザで開くだけで動作します。公開時は同じファイルを静的配信します。

- PC：右矢印を押して走る。離すか左矢印で休む。Space / 上矢印でジャンプ。
- スマホ：道のタップで走行を切り替え、上スワイプでジャンプ。画面下のボタンも利用可能。
- 一時停止ボタンで停止・再開。別のタブへ移ると自動停止。
- 手紙を4分以内に配達すると10両。所持金と配達回数をlocalStorageへ保存。
- スタミナは走行とジャンプで減り、停止中に回復。低スタミナでは減速。
- 荷車・旅人・水たまり・犬に当たると減速。画面上の音ボタンで自作音を有効化。

標準速度の走行時間は約171秒。障害物と休憩を含め約3〜4分が目安です。
保存を禁止したブラウザでもプレイ可能ですが、記録は保持されません。
Canvasによる視覚ゲームのため、スクリーンリーダーのみでのプレイには対応していません。

## 素材・ライセンス

Canvasの背景、人物、障害物はすべてソース内の自作図形です。
音はWebAudioの自作五音音階フレーズと効果音。外部素材・外部フォントは使用していません。
コードと同梱素材はMIT License（LICENSE参照）。個人名・メールアドレスを含みません。
ログイン・広告・課金・解析・外部通信はありません（初回の静的ファイル配信を除く）。

## 改造

単一 `index.html` の冒頭定数 `ROUTE` / `LIMIT` / `SPEED` が距離・制限時間・走行速度です。
`update` がルール、`draw` が描画、`obstacles` が障害物の配置を担当します。
ライブラリやビルド手順は不要です。60fpsを目標にrequestAnimationFrameを利用し、描画解像度を2倍までに抑えています。
